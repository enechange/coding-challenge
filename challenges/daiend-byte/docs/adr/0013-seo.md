# ADR-0013: SEO 方針（メタ / OGP）

## Status

Accepted

## Context

シミュレーション LP としての発見性・共有性を担保する。SPA でも最低限の SEO 対応を設計に含める。レンダリング方式（CSR/SSR/SSG の選定）は [ADR-0002](./0002-nextjs-app-router.md)（Next.js App Router）で決定済み。本ADRはその決定を前提としたメタ情報の設計に集中する。

## Decision

### メタ情報

- `app/simulation/electricity/page.tsx` に静的な `metadata` オブジェクトをエクスポートする（`generateMetadata` による動的生成は不要。URLパラメータ等で内容が変わらない単一静的ページのため）
- `title`/`description` は design.png のコピー（「電気代からかんたんシミュレーション」「検針票を用意しなくてもOK いくらおトクになるのか今すぐわかります！」）を反映した内容にする
- `lang="ja"` は `app/layout.tsx` の `<html>` タグに設定
- `viewport` は Next.js の `viewport` エクスポートで `width=device-width, initial-scale=1` を明示

```tsx
export const metadata: Metadata = {
    title: '電気代からかんたんシミュレーション｜電気料金比較',
    description:
        '検針票を用意しなくてもOK。郵便番号と現在のご契約内容を入力するだけで、電気代がいくらおトクになるか今すぐわかります。',
};
```

### OGP / Twitter Card

- OGP画像は用意せず、`title`/`description`/`type`/`locale` のみ設定する
- Twitter Card は `summary`（画像なし）を使用
- [ADR-0012](./0012-performance.md) で「photographicな画像は使わない」と決めた方針と整合させ、OGP画像の新規制作（課題スコープ外のデザイン作業）を避ける

### 構造化データ

- 導入しない
- このページは記事・商品・FAQ等いずれのschema.org型にも強く適合せず、無理に適用すると実態と乖離した構造化データになるリスクがある
- リッチリザルトの恩恵が見込めるページタイプではないため、実装コストに見合わない

### robots.txt / sitemap.xml

- どちらも用意しない
- robots.txt がなくてもデフォルトでクロールは許可されるため機能的な問題はない
- ページ数が1つのみのため sitemap.xml の実質的な価値がほぼない
- 提出形態を踏まえ最小限で、という意図的な非実装の判断

### 見出し構造とセマンティックHTML

- ページタイトル「電気代からかんたんシミュレーション」を `<h1>`（1ページに1つ）
- 各セクション見出し（「郵便番号をご入力ください」等3つ）を `<h2>`
- 各セクションは `<section>` で囲み、フォーム全体は `<form>`、関連フィールド群は `<fieldset>` + `<legend>` で意味的にグルーピングする
- `fieldset`/`legend` はスクリーンリーダーでの読み上げに寄与し、[ADR-0018](./0018-accessibility.md)（a11y）の土台にもなる。視覚的なスタイリング（デフォルト枠線の除去等）は実装時に対応

## Consequences

- 正: メタ/OGPの設定項目が定義されており、SEO・共有性の最低限の要件を満たす
- 正: 見出し構造とセマンティックHTMLがa11y方針（[ADR-0018](./0018-accessibility.md)）の土台にもなる
- 正: 構造化データ・robots.txt・sitemap.xmlを意図的に見送ることで、実態と乖離した実装や過剰な作り込みを避けている
- 負: OGP画像を用意しないため、SNS等でのシェア時の視覚的訴求力は限定的（スコープ外として許容）
